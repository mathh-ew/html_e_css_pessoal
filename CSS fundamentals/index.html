The Basic Language of the Web: HTML

Posted by Laura Jones on monday, 21st 2017

All modern websites and web applications are built using three fundamental technologies: HTML, CSS and JavaScript These are the languages of the web.

in this point lets focuson Html. We will learn what HTML, is all about , and why you too should learn it.

What is HTML?

HTML stands for HyperText Markup Language. its a markup language that web devs use to structure and describe the content of a webpage (not a programming language).

HTML consists of elements that describe different types of content: paragraphs, links, headings, images, video, etc. Web rowsers understand HTML and render HTML code as websites.

in HTML, each element is made up of 3 parts:

  1. The opening tag
  2. The closing Tag
  3. The actual element
